쉼표 일기

하루에 쉼표 하나. 고마웠던 일 세 가지와 하루 메모를 적는 개인용 감사 일기 앱입니다.

  • 감사 일기 — 하루 감사 세 가지(무엇 · 왜 · 태그)와 기분 · 하루 메모
  • 시간 · 휴일 — 남은 시간 보기와 쉬는 날 계획
  • AI 도우미(선택) — 사용자가 직접 넣은 API 키로, 감사를 대신 쓰지 않고 질문만 건넵니다
  • 기기 간 동기화(선택) — 사용자 본인의 Google 드라이브 앱 전용 폴더를 통해 안드로이드 폰과 Mac 사이에서 기록을 맞춥니다

데이터는 어디에 있나요?

쉼표 일기에는 개발자 서버가 없습니다. 모든 기록은 사용자의 기기에 저장되며, 동기화를 켜면 사용자 본인의 Google 드라이브 안 이 앱 전용 숨김 폴더에만 저장됩니다. 드라이브의 다른 파일은 읽거나 바꾸지 않습니다.
